# Step 5 — Decision quiz before implementation

Issues the code cannot answer (versioning policy, whether to enforce a process gate, a bug whose fix may already be in main) need the user's decision, not a guess. Collect **all** open questions and ask them in **one** interactive quiz: one question per decision, recommended option first, choices concrete enough to execute directly from the answer. Do not start implementation before the quiz is answered.

Skip this phase when every remaining issue has a fully determined fix at HEAD.
