# Prose Style — Study Roadmap Builder

The user has an explicit writing standard for this repo — a repo AGENTS.md
carries the full rules and is the source of truth; read it before writing
docs in that repo. These are the parts most likely to be corrected:

- **No trailing parenthetical in a header.** Write `## Gap`, not
  `## Gap (what I still don't get)`; `## Study checklist`, not
  `## Study checklist (all concepts in this section)`. The user explicitly
  hates the `## Header (...)` pattern. Parens are fine mid-title as an
  example list (`## WEEK09 — Organelle detail (ER, Golgi, mitochondria)`
  is OK).
- **No emoji.** Ban by default.
- **Lead with the point; keep concrete facts.** No throat-clearing openers,
  puffery, or mic-drop endings. End on the last concrete point or next
  action.
- **No invented claims.** Don't add sources, stats, or examples that
  aren't in the material being edited.
- **Plain, active voice.** Use "is"/"has" when clearer; complete
  sentences; no synonym cycling; no dramatic binary contrasts ("not X,
  it's Y") or colon reveals.
