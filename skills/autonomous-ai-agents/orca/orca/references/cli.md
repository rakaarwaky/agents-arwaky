# Orca CLI — worktrees, terminals, repos, automations, artifacts, browser

Operate Orca-managed worktrees, folder contexts, terminals, repos, automations,
artifacts, skill sharing, worktree comments, and Orca's embedded browser through
the `orca` CLI.

Prefer this over raw `git worktree`, ad hoc PTYs, or Computer Use when Orca
state is involved. Use Computer Use only when a visible window needs GUI
control that a CLI, filesystem, or API cannot do.

## Load the version-matched guide

```text
ORCA skills get orca-cli
```
