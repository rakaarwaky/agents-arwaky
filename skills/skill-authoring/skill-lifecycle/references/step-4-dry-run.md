# Step 4: Dry-run & approval

Generate the planned prune report in the shape `step-7-verify-report.md` defines; present it and ask: *"Here is the planned prune. Shall I proceed with the git snapshot and execute these changes?"*

Wait for confirmation. With `--auto` or `--evolution`, skip this gate and proceed straight to Step 5.
