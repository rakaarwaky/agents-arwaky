# Catalog Format

`CATALOG.md` lives at the skills root and is generated by the pack CLI (`skills/skill-authoring/scripts/cli.py catalog`).

Expected location:

```text
skills-root/CATALOG.md
```

## Tables

The catalog contains two tables.

### Categories table

Columns:

```text
| Category | Description | Skills |
```

This table gives a high-level map of the library. The category description is read from each category's `DESCRIPTION.md`.

### Skills table

Columns:

```text
| Skill Name | Category | Description | Path |
```

This table is the main discovery index. The Librarian should read this table instead of opening every skill file.

## Rules

- Rebuild the catalog after moves, archives, category creation, or frontmatter repairs.
- Do not treat the catalog as the owner of category descriptions. Category descriptions are owned by `category/DESCRIPTION.md`.
- Pipe characters in descriptions are escaped as `&#124;`.
- If the catalog is missing or stale, rebuild it before discovery or audit.
- The catalog is generated. Manual edits may be overwritten by the next rebuild.

## Completion criteria

- The Skills table lists every `category/skill/SKILL.md` found by the scanner.
- Every category row has a description or explicitly shows missing `DESCRIPTION.md`.
- The catalog is valid Markdown and can be searched without opening individual skill files.
