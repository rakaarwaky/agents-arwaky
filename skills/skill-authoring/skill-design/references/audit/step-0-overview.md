# Audit — Step 0: Overview

Mechanical audit for a SKILL.md — before publishing (after create/improve) or on demand (`--audit`). Design rules are Global Rules in `SKILL.md`; these files hold what they do not: the full key table, the validator's rule catalog, naming/description/content detail, the reference-pattern decision, the information-distribution test, and the checklists.

**Goal:** make the target skill(s) pass `aa skills lint` and the pre-publish checklist — fix structure, naming, frontmatter, and dangling references.

Run the steps in order; each links to the next.

| Step | File | What it holds |
