# Step 4: Group

Form candidate clusters so Step 5 can classify them.

**Goal:** cluster skills by semantic scope, verified against body content.

## Clustering

Cluster skills by semantic scope using `description` and trigger terms; verify clusters against body content (two descriptions that rhyme can be different jobs).

## Completion

- Skills are grouped into clusters by semantic scope.
- Each cluster is checked against body content, not description alone.
- Every skill in the inventory sits in exactly one cluster.
