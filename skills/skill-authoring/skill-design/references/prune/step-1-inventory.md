# Step 1: Inventory

List every skill folder in the audit root; read each `SKILL.md` frontmatter and body.

## Commands

- `aa skills list` — enumerate every skill in the pack; one row per skill (name + description).
- `aa skills read <name>` — read a skill's full `SKILL.md` when the list row is not enough to judge scope or overlap.
- `aa skills discover <query>` — find skills that share the same tooling or purpose before classifying a cluster (Step 3).
