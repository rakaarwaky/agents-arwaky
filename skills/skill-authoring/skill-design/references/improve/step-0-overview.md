# Improve — Step 0: Overview

Recipe for the improve step. Verification after any edit is the `aa skills lint` gate — these files add only the edit actions that precede it.

**Goal:** make an existing `SKILL.md` follow the body shape and lint standard without losing the skill's intent.

Run the steps in order.

| Step | File | What it does |
| ---- | ---- | ------------ |
| 1 | [`step-1-scope.md`](step-1-scope.md) | Resolve the target skill set from the path. |
| 2 | [`step-2-body-format.md`](step-2-body-format.md) | Enforce the `# Title` / `## Global rules` / `## Routing` body shape. |
| 3 | [`step-3-apply.md`](step-3-apply.md) | Apply the 9-point edit recipe; verify with lint + pre-publish checklist. |
