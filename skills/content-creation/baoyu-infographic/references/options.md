# Infographic — Options and Galleries

**Goal:** pick a layout, a style, an aspect, and a language, and know where each
definition lives.

## Options

| Option | Values |
|--------|--------|
| Layout | 21 options (see Layout Gallery), default: bento-grid |
| Style | 21 options (see Style Gallery), default: craft-handmade |
| Aspect | Named: landscape (16:9), portrait (9:16), square (1:1). Custom: any W:H ratio (e.g., 3:4, 4:3, 2.35:1) |
| Language | en, zh, ja, etc. |

## How to Combine

Freely combine any layout with any style. Start from the keyword shortcuts and
recommended combinations in `references/recommendations.md`; otherwise match the
data structure to a layout and the content tone to a style.

## Completion

- Every option (layout, style, aspect, language) has a chosen value, defaulting
  to `bento-grid` + `craft-handmade` when the user did not specify.
- Each chosen layout/style resolves to an existing definition file.
