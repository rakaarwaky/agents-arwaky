# Step 3 — Patterns

## Cut targets (improve mode)

| Doc size | Target |
|----------|--------|
| >200 lines | Cut 5–15%. |
| >300 lines | Cut 15–30%. |
| > 500 lines | Cut 30–50%. |

Never cut meaning: every action, constraint, exact name, and `CONFLICT:` line survives.

## Create skeleton (`--create`)

Use the smallest structure that fits the task; skip any section that would be empty.

| Doc type | Skeleton |
|----------|----------|
| Overview | `Objective`. |
| Workflow | `Purpose` → `Steps` → `Checks`. |
| Reference | One table per topic: name → purpose. |
