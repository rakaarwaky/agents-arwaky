# Step 3 — Patterns

## Cut targets (improve mode)

| Doc size | Target cut |
|----------|------------|
| 201–300 lines | 5–15% |
| 301–500 lines | 15–30% |
| >500 lines | 30–50% |

Cuts must pass the `Meaning` check in `step-5-report.md`.

## Create skeleton (`--create`)

Use the smallest structure that fits the task; skip any section that would be empty.

| Doc type | Skeleton |
|----------|----------|
| Overview | `Objective`. |
| Workflow | `Purpose` → `Steps` → `Checks`. |
| Reference | One table per topic: name → purpose. |
