# LLM Writing — Information Placement

Phase: Pre Draft.

**Goal:** every fact has exactly one owner location; nothing is restated that the reader can derive in one read.

## Placement Table

| Info type                    | Location                 | Rule                                                    |
| ---------------------------- | ------------------------ | ------------------------------------------------------- |
| Needed on every task         | Top of text, or root doc | Cell ≤ 20 words. Goal, commands, hard constraints first |
| Needed for one or more parts | Separate section or doc  | Root lists it with cell ≤ 20 words                      |

## Cell-Width Rule

Every table cell holds ≤ 20 words. No paragraphs in cells.

## Human-Only Content Rule

Do not add content meant only for human readers (persuasion, warmth, entertainment). Every sentence must enable an agent action.
